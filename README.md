HR Sports Day Team Assignment using Genetic Algorithm

โปรเจกต์จัดแบ่งทีมกีฬาสีพนักงาน (Team Pink และ Team Red) จำนวน 358 คน โดยใช้อัลกอริทึม Genetic Algorithm (GA) พัฒนาด้วย NumPy และ Pandas เพื่อจัดสรรให้ทั้งสองทีมมีความสมดุลสูงสุดในทุกมิติ

🎯 เป้าหมายการจัดทีม (Optimization Objectives)

จำนวนสมาชิกเท่ากันเป๊ะ: แบ่งทีมละ 179 คน (50:50)

ความสมดุลทางกายภาพ: ค่าเฉลี่ยน้ำหนัก (weight), ส่วนสูง (height) และอายุ (age) ใกล้เคียงกัน

สัดส่วนเพศ: กระจายเพศชายและหญิงให้สมดุลในแต่ละทีม

การกระจายตัวตามแผนก: แบ่งพนักงานในแต่ละแผนกออกเป็น 50:50 เพื่อส่งเสริมความสามัคคีข้ามสายงาน

🧬 โครงสร้างการทำงานของ Genetic Algorithm

Population Size: 150 รูปแบบการจัดทีม

Generations: 80 รอบการวิวัฒนาการ

Elitism: คัดเลือก 15 อันดับแรกที่ดีที่สุดเก็บไว้ในรุ่นถัดไป

Crossover & Repair: ผสมยีนและปรับแก้จำนวนคนให้คงที่ 179 : 179 เสมอ

Mutation: Swap Mutation (อัตรา 40%) สุ่มสลับสมาชิก 1 คู่ระหว่างสองทีม

📂 โครงสร้างไฟล์ในโปรเจกต์

sport-day/
├── Geneticalgorithms.py      # โค้ดหลักสำหรับรันอัลกอริทึมและพล็อตกราฟ
├── HR.csv                    # ข้อมูลตั้งต้นของพนักงาน (Input)
├── HR_sports_day_teams.csv   # ผลลัพธ์รายชื่อพนักงานพร้อมทีมที่ถูกจัด (Output)
├── requirements.txt          # รายการไลบรารีที่จำเป็นสำหรับติดตั้งผ่าน pip
└── README.md                 # เอกสารอธิบายโปรเจกต์


🚀 วิธีติดตั้งและรันโปรแกรม

1. ติดตั้งไลบรารีที่จำเป็น

pip install -r requirements.txt


2. รันโปรแกรม

python Geneticalgorithms.py
